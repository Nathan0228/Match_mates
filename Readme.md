# 见山 · 国科大交友

面向国科大学生的认真交友网站原型。前端 React + Vite，后端 Go，单实例 SQLite。页面含响应式首页、校园邮箱注册、头像与资料填写、学生证人工审核、匹配推荐和双方同意后交换邮箱。

> 当前是可运行的开发原型，**不应在缺少运营与合规准备时直接开放真实用户注册或收费**。会费采用静态收款码与人工核款，没有支付平台回调；用户提交交易单号不代表实际到账。正式上线前还需核实收款、退款、隐私和运营要求。

## 本地运行

需要 Node.js 20+ 和 Go 1.26+。

```powershell
cd api
if (!(Test-Path .env)) { Copy-Item .env.example .env }
# 在 .env 填写 ADMIN_EMAIL，以及 TMDB_READ_ACCESS_TOKEN 或 TMDB_API_KEY
go run .
```

Go 服务启动时读取 `api/.env`，已有的进程环境变量优先；`api/.env.example` 只是无密钥的模板，不会被读取。修改 `.env` 后须重启 Go 服务。如果后端所在网络无法连接 `api.themoviedb.org` 或 `image.tmdb.org`，请在启动前为 Go 进程配置可用的 `HTTPS_PROXY`（例如本地代理的 HTTP 地址），或将 Go 服务部署到可访问 TMDB 的网络。仅填写 API Key 无法解决网络连接超时。海报由 Go 服务转发，因此两处 TMDB 域名都需要后端可访问。

另开终端：

```powershell
cd web
npm install
npm run dev
```

打开 `http://localhost:5173`。开发环境没有配置 SMTP 时，注册响应会在网页中显示测试验证码。管理员账号先在“管理中心”上传收款码并生成测试代码；普通账号可以兑换代码，或创建订单并提交测试交易单号，由管理员在“会费核款”中确认后再上传测试证件。测试时请只使用自己有权使用的邮箱和文件。原“模拟支付”入口已停用。

## 核心规则

- 邮箱仅接受 `@mails.ucas.ac.cn`。邮箱验证后才可登录；忘记密码时可用校园邮箱接收 10 分钟有效的验证码，新密码设置成功后旧会话失效。会费、学生证审核和完整资料均完成后才进入匹配池。
- 注册时选择性别和希望认识的性别，保存后不可修改；旧账号若尚未填写，可补填一次。交友方向要求双向一致：`男→女 / 女→男`、`男→男`、`女→女`。数据库先按双方性别和意向筛选候选人，组间不混流。
- 按双方方向和审核状态筛选候选人，再依据共同价值、兴趣与相处习惯计算资料契合分，展示前 30 人。分数仅用于排序，不代表好感概率；不设固定 80% 门槛。字段、权重、缺失值规则和研究依据见 [Algo.md](Algo.md)。
- 在“发现同频”点击“查看完整资料”，可阅读对方的介绍、兴趣、相处偏好和契合原因，再决定是否表达“想认识”；详情只展示当前符合匹配条件的候选人。
- 单方点击“想认识”不会提供联系方式。双方都点击后，`/api/matches` 才返回各自的校园邮箱。
- 页眉头像旁的消息图标显示未读数量。双向匹配、学生证审核和会费核款会产生站内提醒；管理员会收到待审学生证与待核款订单的提醒。消息可逐条或全部标记已读，管理员待办处理后会从提醒列表移除。
- 管理员可在“管理中心 → 消息通知”填写标题与正文，预览后向当前所有已注册的非管理员用户发布站内公告。用户可在消息提醒中点开阅读完整内容；管理员可查看最近 30 条发布记录和每条消息的发送人数。
- 学生证文件只允许管理员查看；完成审核后服务器删除文件。上传限制 5 MB，支持 JPG、PNG、WebP、PDF。
- 会费固定 **9.90 元**。兑换码可免除全部会费，由管理员设置生效时间、结束时间、最多使用次数与启停状态；使用次数在成功兑换时增加。折扣码按支付比例计算，例如 **80% 表示八折、实付 7.92 元**；管理员设置有效期与启停状态。创建折扣订单时锁定应付金额，之后停用或到期不改变该订单金额。折扣码使用次数只在管理员确认到账后增加。
- 新生成的优惠代码可在管理员“代码管理”中再次复制；数据库保存代码摘要及加密后的完整代码，列表接口仅返回尾号。旧版代码只保存了摘要，无法恢复完整内容，需另行生成新代码。生产环境须设置固定的 `PROMO_CODE_KEY`（64 位十六进制随机值）并妥善备份；更换或丢失密钥后，已生成代码仍可兑换，但不能再从后台复制。
- 管理员可分别上传、启停微信与支付宝静态收款码，并设置收款方名称。用户创建订单后按页面金额扫码支付，再提交交易单号；管理员须在自己的收款账户核对渠道、收款方、交易单号和实收金额，确认后才把 `paid` 设为 1。订单保存创建时的收款方与收款码版本；收款配置变更后，未付款的旧订单需要取消并重建。退回的订单可修正交易单号再次提交；同一渠道与交易单号不能为两笔订单重复核款。所有订单状态变化和代码实际使用方式均写入数据库。
- `ADMIN_EMAIL` 指定的账号可进入“管理中心”，查看注册与审核概览、搜索待审申请、预览证件并通过或拒绝，管理代码与收款码、人工核款。证件审核会记录处理人、决定和时间；近期 30 条可在审核记录中查看。旧版已完成的审核没有历史记录。
- 管理员可在“用户管理”按邮箱、昵称或用户 ID 分页检索，查看用户资料及入驻状态，并填写原因停用或恢复账号。停用会清除该用户所有会话，使其无法登录、使用匹配或继续出现在他人的匹配结果中；恢复后可重新登录。管理员不能停用自己的账号，状态变更和原因会留存操作记录。会费核款和学生证审核仍在各自的管理页操作。
- 登录和注册只填写邮箱 `@` 前的用户名，页面固定显示 `@mails.ucas.ac.cn`，API 仍校验完整邮箱。头像可在“我的介绍”单独上传，限制 2 MB、JPG 或 PNG；服务器解码并重新编码为 JPEG，去除原图元数据，仅向本人及交友方向互相符合的合格用户提供读取。
- 在“我的作品清单”填写电影或剧集名称后，前端会延迟请求 Go 后端搜索 TMDB，并自动匹配有海报的结果；若匹配不准确，可从候选作品中更换。海报路径随资料保存，在预览和可匹配用户的资料展示页由 Go 服务转发图片；TMDB 不可用时仍可只保存作品名称。后端设置 `TMDB_READ_ACCESS_TOKEN`（推荐）或 `TMDB_API_KEY`，不要将密钥放入 Vite 前端变量。

## 前端模块

- `web/src/App.jsx`：会话、弹窗和页面切换。
- `web/src/components/`：页眉、页脚、头像、滚动渐入、空状态和提示等通用组件。
- `web/src/features/auth/`：认证对话框与固定后缀邮箱输入。
- `web/src/features/landing/`：首页各区块。
- `web/src/features/dashboard/`：入驻进度、发现、双向匹配与资料编辑；`payment/` 实现会费、订单与使用记录；`admin/` 实现审核、代码、收款码与核款管理。
- `web/src/lib/api.js`：统一的 API 请求和头像 URL；`web/src/styles/`：按页面职责拆分的样式。移动端使用底部主导航、安全区留白和适合触控的操作尺寸；内容进入视口时渐入，系统要求减少动态效果时直接展示。资料、会费与管理页面按需加载，头像延迟解码。

## Cloudflare + GitHub 部署方案

1. 将此仓库推送 GitHub。在 Cloudflare Pages 中连接仓库，根目录设为 `web`，构建命令 `npm run build`，输出目录 `dist`。`web/functions/api/[[path]].js` 会把同源 `/api/*` 请求转发给 Go 服务。
2. Go API 用 `api/Dockerfile` 部署在支持持久磁盘的容器平台或自有服务器，并挂载 `/data`。SQLite 数据库、学生证临时文件与收款码图片必须位于该持久磁盘；运行多个 API 实例前需改用共享数据库和对象存储。
3. Pages 中配置环境变量 `API_ORIGIN=https://你的Go服务域名`。Go 服务设置 `APP_ENV=production`、`FRONTEND_ORIGIN=https://你的Pages域名`、`ADMIN_EMAIL`、SMTP 配置、`TMDB_READ_ACCESS_TOKEN`（或 `TMDB_API_KEY`），以及固定的 `PROMO_CODE_KEY`。不要提交密码或密钥。TMDB 要求展示来源与免责声明；若收费业务符合其商业用途定义，应先确认所需授权。
4. 静态收款码不会返回可信的支付结果。安排管理员核对每笔实际到账，再通过后台订单；不要根据用户提交的交易单号自动开通。若将来接入支付平台，应验证回调签名、订单号与实际金额并处理重复通知。旧 `/api/payment/create` 返回 410，不能继续模拟开通会费。
5. 正式开放前，补充用户协议、隐私告知、退款与投诉机制、备份、访问限流和证件保留周期，并核实收费与学生证处理所需的合规要求。

Cloudflare Pages 可以直接从 GitHub 构建 React 前端；本项目的常规 Go HTTP 服务需要单独运行。Pages Functions 负责保持浏览器请求同源，避免将 API 地址写进前端。
